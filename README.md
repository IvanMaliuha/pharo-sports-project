# Проєктування класів — командний проєкт, варіант 3

## 1. Опис завдання

Мета проєкту — спроєктувати та реалізувати класи для моделювання спортсменів у Pharo Smalltalk.

Базова сутність `Sportsperson` описує прізвище, вік і громадянство. Клас `TennisPlayer` додатково зберігає світовий рейтинг і призові за три останні турніри. Клас `FootballPlayer` зберігає клуб, величину річного контракту та кількість забитих за рік голів.

Програма має обчислювати доходи спортсменів, порівнювати їх за доходом, виконувати арифметичні операції, виводити інформацію про об’єкти та перевіряти функціонал модульними тестами.

Проєкт також передбачає роботу з колекцією спортсменів, збереження даних у файлах різних форматів і демонстрацію завантаження даних зі сховища.

## 3. Технології

- Pharo 9
- Smalltalk
- Git
- GitHub

## 4. Структура проєкту

- `src/` — класи та реалізація функціоналу.
- `tests/` — модульні тести.
- `data/` — вхідні дані та результати виконання.
- `docs/` — документація командної роботи.
- `README.md` — опис завдання, учасників та інструкції.

## 5. Запуск і перевірка

1. Завантажити вихідні файли проєкту.
2. Відкрити їх у Pharo 9.
3. Завантажити класи та демонстраційні методи.
4. Запустити модульні тести.
5. Виконати демонстрацію роботи з колекцією та збереженням даних.

Детальні інструкції та фактичні результати будуть доповнені після реалізації відповідних частин.
